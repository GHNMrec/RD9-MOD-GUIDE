# RD-9 Mod Guide

Single-file, phone-friendly build guide for the Behringer RD-9 (TR-909 clone) modifications.

## Contents

- `rd9-mod-guide.html` — the full guide (self-contained: inline CSS, JS, SVG diagrams, and photos). No build step, no network dependencies.
- `.nojekyll` — tells GitHub Pages to serve files as-is.

## Use

Open `rd9-mod-guide.html` in any browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and visit `https://<your-username>.github.io/rd-9-mod-guide/rd9-mod-guide.html`.

Checklist progress and parts tracking are stored in the browser's localStorage on each device.

## Safety

The RD-9 contains mains-derived and high-voltage-adjacent circuitry. Power off, unplug, and discharge large reservoir capacitors before any physical work. Verify every value against the schematic before soldering.
